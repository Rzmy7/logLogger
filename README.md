# Log Analytics Platform

A high-performance log analytics platform.

## Project Structure

- `cmd/`: Main applications and entry points for the project.
- `internal/`: Private application and library code.
- `migrations/`: Database migration scripts and files.
- `deployments/`: Deployment configurations, Dockerfiles, K8s manifests.
- `docs/`: Documentation and design specs.
- `scripts/`: Helper and automation scripts.
- `benchmarks/`: Performance benchmarks.
- `test/`: Additional test suites and test data.
- `Makefile`: Build and automation tasks.
